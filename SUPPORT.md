# Support

Start with the [README](README.md) for installation, league rules, save
compatibility, and the latest packaged version. Back up your league data before
upgrading. Older executables may not read a save upgraded by a newer release.

## Questions and problems

Search [existing issues](https://github.com/Geauga/elo_calculator/issues) first.
Use the [issue chooser](https://github.com/Geauga/elo_calculator/issues/new/choose)
for a bug report, feature request, or usage question. Support is provided on a
best-effort basis; there is no guaranteed response time.

Include your application version or source commit, Windows/OS version, whether
you run the EXE or Python source, and the smallest steps that reproduce the
problem. For source runs, include the Python version. For visual problems, note
the theme and display scaling and attach a redacted screenshot if useful.

Do not upload your entire application-data directory. Remove player names and
other personal data from examples, logs, and screenshots. Prefer a new synthetic
league with the same settings. Never include passwords, tokens, private contact
details, or unredacted backups.

## Private or sensitive reports

Do not report vulnerabilities in public issues; follow [SECURITY.md](SECURITY.md).
For harassment or conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
